# Synthetic Part 11 discharge corpus

This project is fictional test input for exercising the Part 11 reference pack.
Its requirements, people, repositories, and evidence locations use reserved
`example.invalid` names. It contains no customer records or regulatory text.

The discharge test copies this corpus into a temporary Git repository, creates
and verifies SSH-signed commits and a signed tag at runtime, then stores
tool-produced evidence and manually authored discharge facts in temporary
locations. Nothing generated by the test is checked in.
