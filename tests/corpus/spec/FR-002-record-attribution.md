# FR-002: Attribute synthetic record changes

## Description

The fictional `example.invalid` records service SHALL associate each accepted
change with the named fictional reviewer who approved it.

## Acceptance Criteria

| ID | Criteria | Verification |
|----|----------|--------------|
| FR-002-AC-1 | An accepted change identifies its synthetic reviewer. | Test |

## Dependencies

- Upstream: the fictional `example.invalid` approval directory.
