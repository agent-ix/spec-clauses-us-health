# US Health-Law Compliance Pack

This repository is the spec-first home for the US Health-Law Compliance Pack.
The initial specification defines a clause-only module and the 21 CFR Part 11
set. The implementation and CI are tracked separately; this repository does
not yet publish clause content or claim legal compliance.

See [`spec/spec.md`](spec/spec.md) for the module boundary, clause identifiers,
applicability, expected outputs, customer-owned obligations, source, and shared
pack conventions.
